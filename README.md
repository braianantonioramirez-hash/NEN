# NEN

Grabador de pantalla para Windows que **tapa solo** tus contraseñas, tarjetas,
claves de API y notificaciones antes de que salgan en el video o en el vivo.

## Descargar
Andá a **Releases** (a la derecha) y bajá `NEN-0.1.0-win-x64.zip`.
Las instrucciones están en el `LEEME.txt` que viene adentro.

## Requisitos
- Windows 10 (2004 o más nuevo) o Windows 11
- FFmpeg: `winget install Gyan.FFmpeg`

## Reportar errores
Abrí un **Issue** contando qué hiciste, qué esperabas y qué pasó.
No subas videos con datos reales.
